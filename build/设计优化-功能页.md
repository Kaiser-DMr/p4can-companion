# 「功能」页菜单优化方案（v2.2 设计稿）

> 沿用 v2.0 的设计 token（颜色 / 字号 / 圆角 / 间距），只重组"功能"页的信息架构与导航方式。
> Figma 交付：Frame 393×852，组件 `CategoryChip / CategoryBar / ModuleRow / SectionHeader`。

---

## 1. 问题

优化前「功能」页是**一条 19 项的长列表**（4 个分组，靠 section 标题分隔）：

- 从"驾驶辅助"翻到"高级与兼容"要滚 2–3 屏，找 `踏板映射`、`常驻 AP` 这类低频项成本很高；
- 分组标题只在滚动时短暂出现（尤其单分组较长时），用户很难建立"一共有哪几类"的整体印象；
- 分组之间没有快速跳转，回到顶部才能换类。

## 2. 方案：顶部固定「分类条」+ 过滤列表

```
┌──────────────────────────────┐
│  功能                        │  ← 大标题（滚动时收起）
├──────────────────────────────┤
│ [全部 19][驾驶辅助 6][车身 3][实验室 6][高级 4] │ ← 固定，不随列表滚动
│ 实验室功能 · 6 个模块          │ ← 当前范围摘要
├──────────────────────────────┤
│ 实验室功能 6                  │ ← 单分类时仅一个分组头
│ ┌──────────────────────────┐ │
│ │ R79 AP 控制            › │ │
│ │ 实验室功能总开关        › │ │
│ │ …                        │ │
└──────────────────────────────┘
```

### 分类与数量（与固件模块一一对应，无删减）

| 分类 | 数量 | 模块 |
|---|---|---|
| 全部 | 19 | 全部分组 |
| 驾驶辅助 | 6 | NAG / ALC / ULC / TLSSC / DMS / R79·EU |
| 车身与舒适 | 3 | 自动转向灯 / 开门自动取消 / ISA 抑制 |
| 实验室功能 | 6 | R79 AP 控制 / LAB 总开关 / 视觉限速 / 召唤心跳 / 主驾车窗 / CAN 研究捕获 |
| 高级与兼容 | 4 | 地区区服 / 踏板映射 / 常驻 AP / 车型配置 |

## 3. 组件规格

### 3.1 CategoryChip（两种变体）

| 属性 | 未选中 | 选中 |
|---|---|---|
| 背景 | `bg/card`（白/深灰） | `state/info`（蓝） |
| 文字 | `text/primary` 13pt medium | `#FFFFFF` 13pt medium |
| 数量 | 同色 11pt semibold，75% 不透明度 | 白 11pt semibold，75% |
| 图标 | SF Symbol 11pt，跟随文字色 | 同左 |
| 描边 | 0.5pt `text/primary` 8% | 无 |
| 圆角 | Capsule | Capsule |
| 内边距 | 横 12 / 纵 7 | 同左 |
| 间距 | 8 | 8 |
| 无障碍 | `accessibilityLabel = "分类名，N 个模块"` | 追加 `.isSelected` trait |

### 3.2 CategoryBar（Figma：Auto Layout）
- 方向：水平；`padding: 8`（上下）、`itemSpacing: 8`；高度 ≈ 44
- 溢出：横向滚动（`ScrollView(.horizontal)`），选中项自动 `scrollTo(center)`
- 下方摘要行：`caption2`，次级色，内容为「全部 · 19 个模块 / 分类名 · N 个模块」
- 固定：放在列表之外（`VStack { bar; List }`），滚动时始终可见

### 3.3 ModuleRow
- 图标：30×30，圆角 9，`bg/tile` 底，SF Symbol 13pt + tint
- 标题：`body` medium；摘要：`footnote` 次级色，最多 2 行
- 右侧：`StatusChip`（支持 / 不支持，仅在固件回报能力位时出现）+ 系统 chevron
- 行高 ≈ 68（两行摘要），点击整行进详情

### 3.4 SectionHeader
- 图标 + 分类名（`subheadline` semibold）+ 数量胶囊（11pt，8% 底）
- 仅在「全部」与单分类列表顶部各出现一次

### 3.5 SearchField（v2.3 新增）

- 位置：大标题下、分类条上方，**常驻**不随列表滚动
- 规格：高 38，圆角 12，`bg/card` 底 + 0.5pt 8% 描边；放大镜 12pt 次级色
- 占位文案：「搜索模块（如 踏板 / TLSSC / 限速）」
- 清除按钮：有输入时出现，点击清空并收起键盘
- 匹配范围：模块标题 / 说明 / 模块 id / 分类名（大小写不敏感，中英文均可）
- 搜索态：**分类条隐藏**（避免两套筛选打架），摘要改为「搜索「x」· N 个结果」，列表分组头变「搜索结果」
- 空结果：卡片内提示 + 建议关键词 + 「清除搜索」按钮
- 交互：键盘 `.search` 回车收起；列表下滑即收键盘

## 4. 交互与状态

| 状态 | 表现 |
|---|---|
| 默认 | 「全部」选中（蓝），列表按 4 个分组展示 |
| 切换分类 | 0.22s `snappy` 动画过滤列表；分类条自动把选中项滚到中间；轻触觉反馈 |
| 列表滚动 | 分类条固定不动，随时可切换 |
| 未连接 | 列表顶部保留「设备未连接」提示，分类仍可切换 |
| 深色 | 全部走语义色，选中蓝在深色为 `#0A84FF` |
| 空分类 | 理论上不存在（每类至少 3 项）；若未来出现，显示"该分类暂无模块" |

> 备注：曾尝试在分类条两端做渐隐遮罩，实测 iOS 27 的 `ScrollView` 内容绘制在兄弟/覆盖层之上，
> 遮罩无法覆盖胶囊文字，故改为"选中项自动居中 + 标准横滑"，避免出现被生硬切断的胶囊。

## 5. 无障碍

- 分类胶囊可聚焦、可朗读「驾驶辅助，6 个模块」；选中态通过 `.isSelected` 告知读屏
- 列表行合并朗读「标题，摘要，支持/不支持」
- 支持 Dynamic Type：标题与摘要换行，胶囊文字不截断（数量用等宽数字）
- 触控目标：胶囊高度 34 + 内边距，实际命中区域 ≥ 44

## 7. 主要调整点（一句话版）

1. **顶部加固定分类条**：5 个分类 + 数量，随时可见，不再靠滚动找分组。
2. **点击即过滤**：单分类只显示该类模块，19 项长列表变成最多 6 项。
3. **选中态明确**：蓝色实心胶囊 + 白字 + 数量，未选中为卡片底 + 描边；选中项自动滚到可见。
4. **保留全部入口**：默认「全部」仍按 4 组展示，所有 19 个模块与详情页完全不变。
5. **行样式统一**：图标加 30×30 圆角底、支持徽章换成 `StatusChip`，与状态页视觉一致。
6. **顶部搜索框（v2.3）**：全局搜索模块名/说明/关键词，边输边过滤，搜索时自动收起分类条，空结果有引导。
7. **顺带修复两个失效图标**：`window.vertical`、`square.and.line.vertical.square` 不是合法 SF Symbol（已换 `car.side.front.open` / `slider.horizontal.3`）。
