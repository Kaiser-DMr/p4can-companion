# 固件补丁：灯光爆闪（转向灯 0x249 / CAN B）

> 目标仓库：`06066060606060/P4can-universal-unlock`（v3.29.3 分支）
> 补丁文件：`build/firmware-patch/light_strobe.h`
> ⚠️ 本补丁**未在 ESP32 工具链里编译验证**（本机没有 Arduino/ESP-IDF 环境），代码按仓库既有风格与符号编写，请在你本地编译一次；若有符号对不上，按下面「常见编译问题」改。

## 1. 为什么可行

仓库已有完整的 0x249 注入链路：

| 项 | 位置 |
|---|---|
| 帧 ID | `LEFTSTALK_ID 0x249`，DLC 4，CAN B |
| 发送 | `sendStalkFrameCanB(turn, txEpoch, directUser)`（用车上真实帧做模板，改 counter + turn，重算 CRC） |
| 模板 | `stalkFrameSnapshot(cnt, tmpl)` —— 抓不到就拒绝发送 |
| 校验 | `leftStalkChecksum(frame, counter)` |
| 周期入口 | `can_runtime.h` 中 `blinkATxTick();` 所在循环 |

爆闪 = 按频率在 `灯亮` / `IDLE` 之间反复发送。

### 3.3 加 HTTP 端点

`web_api.h` 里，放在 `httpBlinkATxMode()` 附近：

```cpp
static String lightStrobeToJson() {
  String s;
  s.reserve(320);
  JsonWriterArduino jw(s);
  bool active, blocked;
  uint8_t hz, pattern;
  uint32_t durationMs, startedAt, txOk, txFail;
  const char *reason;
  portENTER_CRITICAL(&lightStrobeMux);
  active = lightStrobeState.active;
  blocked = lightStrobeState.blocked;
  hz = lightStrobeState.hz;
  pattern = lightStrobeState.pattern;
  durationMs = lightStrobeState.durationMs;
  startedAt = lightStrobeState.startedAtMs;
  txOk = lightStrobeState.txOk;
  txFail = lightStrobeState.txFail;
  reason = lightStrobeState.blockReason;
  portEXIT_CRITICAL(&lightStrobeMux);

  const uint32_t now = (uint32_t)millis();
  const uint32_t elapsed = active && startedAt ? (uint32_t)(now - startedAt) : 0;
  const uint32_t remaining = active && elapsed < durationMs ? durationMs - elapsed : 0;

  jw.boolean("supported", true);
  jw.boolean("active", active);
  jw.boolean("blocked", blocked);
  jw.string("blockReason", reason ? reason : "");
  jw.u32("hz", hz);
  jw.u32("durationMs", durationMs);
  jw.u32("remainingMs", remaining);
  jw.u32("txOk", txOk);
  jw.u32("txFail", txFail);
  jw.string("pattern",
            pattern == LS_PATTERN_LEFT ? "left" :
            pattern == LS_PATTERN_RIGHT ? "right" : "alternate");
  return s;
}

static void httpLightStrobe() {
  if (server.method() == HTTP_POST) {
    // 允许只改参数（频率/时长/模式），不影响运行状态
    if (server.hasArg("hz")) {
      lightStrobeState.hz = lightStrobeClampHz(server.arg("hz").toInt());
    }
    if (server.hasArg("durationMs")) {
      const long v = server.arg("durationMs").toInt();
      lightStrobeState.durationMs = (uint32_t)constrain(v, 200, 30000);
    }
    if (server.hasArg("pattern")) {
      const String p = server.arg("pattern");
      lightStrobeState.pattern = p == "left"  ? LS_PATTERN_LEFT
                               : p == "right" ? LS_PATTERN_RIGHT
                                              : LS_PATTERN_ALTERNATE;
    }

    if (server.hasArg("enabled")) {
      const bool on = server.arg("enabled").toInt() != 0;
      if (on) {
        // enabled 时必须带上完整参数，避免用到旧配置
        const uint8_t hz = server.hasArg("hz")
            ? lightStrobeClampHz(server.arg("hz").toInt()) : lightStrobeState.hz;
        const uint32_t dur = server.hasArg("durationMs")
            ? (uint32_t)constrain((long)server.arg("durationMs").toInt(), 200, 30000)
            : lightStrobeState.durationMs;
        const String p = server.hasArg("pattern") ? server.arg("pattern") : "";
        const uint8_t pat = p == "left"  ? LS_PATTERN_LEFT
                          : p == "right" ? LS_PATTERN_RIGHT
                                         : LS_PATTERN_ALTERNATE;
        if (!lightStrobeBegin(hz, dur, pat)) {
          server.send(409, "application/json",
                      "{\"ok\":false,\"error\":\"NO_STOCK_TEMPLATE\"}");
          return;
        }
      } else {
        lightStrobeStop(nullptr);
      }
    }
    server.send(200, "application/json", "{\"ok\":true}");
    return;
  }
  server.send(200, "application/json", lightStrobeToJson());
}
```

注册（与其它路由放在一起）：

```cpp
  server.on("/api/lights/strobe", HTTP_GET,  httpLightStrobe);
  server.on("/api/lights/strobe", HTTP_POST, httpLightStrobe);
```

## 4. 上车前的验证顺序

1. 正常开一次转向灯（左/右各一次），让盒子抓到真实 0x249 模板；
2. `GET /api/lights/strobe` → `supported=true, blocked=false`；
3. 低速、空旷场地，`POST ...enabled=1&hz=2&durationMs=3000&pattern=left`，确认 3 秒后自动停；
4. 再试 `hz=6`，观察是否有丢帧（`txOk` 增长是否线性）与车身是否报错；
5. 最后再测 `alternate`。

## 5. 常见编译问题

| 报错 | 处理 |
|---|---|
| `stalkFrameSnapshot` 未声明 | `light_strobe.h` 必须在 `vehicle_logic.h` **之后** include |
| `portMUX_TYPE` 未定义 | 确认 `#include <Arduino.h>` 在 `.ino` 顶部（已有）；或改用 `portMUX_INITIALIZER_UNLOCKED` 同文件声明 |
| `LS_PATTERN_*` 未定义 | 头文件未被 include（检查拼写） |
| `sendStalkFrameCanB` 未声明 | 同上，是 `vehicle_logic.h` 内的 static 函数 |

## 6. 未验证 / 需实车确认

1. `STALK_DOWN_1` 与「左转」的对应关系（本补丁假设下拨=左，仓库 `dirToTurn` 只定义了方向序号 1/2）；
2. 车身对 8Hz 拨杆报文的容忍度（可能有丢帧或故障计数）；
3. 模板缺失时的 409 分支在 App 上会显示为「启动失败：NO_STOCK_TEMPLATE」，这是预期行为。

## 7. App 侧已完成（v3.0）

模块「灯光爆闪」已进 `FeatureCatalog`（车身与舒适）：

| 控件 | 参数 |
|---|---|
| 启动爆闪（toggle） | `enabled` + 同时提交 `hz/durationMs/pattern` |
| 频率（滑杆） | `hz` 1–8，单位 Hz |
| 持续时间（滑杆） | `durationMs` 500–10000，单位 ms |
| 模式（选择） | `alternate / left / right` |

状态读取：`active / blocked / blockReason / hz / durationMs / remainingMs / txOk / txFail / pattern`。
固件未打补丁时，页面会显示「读取中…」而不是假开关（v1.8 的规则）。
