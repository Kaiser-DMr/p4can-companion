## 2. 为什么用「白字红底」而不是「红字白底」

AO3 字标是**单色线稿**，笔画偏细。放在浅色底上时，小尺寸（60px）只剩几条淡红细线，整体单薄、没有"物件感"；
反过来用品牌红 `#990000` 系的深红玻璃底 + 纯白字标：

- 对比度最高（白 on 深红 ≈ 8:1），40px 下仍能读出形状；
- 与 iOS 26/27 图标语言一致：**有色底 + 白色图形**（音乐、播客、健身都是这个结构）；
- 深红本身就是 AO3 的品牌色，不算改造，只是把底色与图形对调。

## 3. iOS 27（Liquid Glass）规范落实

| 规范项 | 做法 |
|---|---|
| 画布 | 1024×1024，**不烘焙圆角**，圆角交给系统 squircle |
| 不透明 | 默认/深色均为不透明 RGB；着色版同样不透明深底 |
| 安全区 | 字标占画布 **72%**，四周留白 ≥14%，避开四角裁切 |
| 三套外观 | `default / dark / tinted` 写入 `Assets.xcassets`（`appearances: luminosity`） |
| 无文字 | 图标内无文字，避免小尺寸糊化与本地化问题 |
| 笔画重量 | 最细笔画 ≈22px@1024（60pt 下 ≈1.3px），与系统图标接近 |

## 4. 材质做法

**背景（红玻璃）**
- 径向渐变：`#B2181E`（左上受光）→ `#8C0A10` → `#5C0206` → `#2C0003`（边缘沉入近黑红）
- 左上大面积柔光 + 中心柔光，幅度仅 10% / 14%，避免"塑料红"
- 一条极淡斜向反射带（10%），暗示表面是玻璃而非印刷色
- 暗角 26%，把视线收回中心

**字标（白色玻璃）**
- 背光：轮廓模糊 26px、9% 白色，让白字在深红上"浮"起来（小尺寸更清晰）
- 投影：轮廓模糊 10px、下移 5px、34% 不透明度，色 `#300004`
  —— 投影在**带 24% 内边距的画布**上计算，否则会被画布边界裁成方块
- 受光：RGB 施加 0.90→1.04 垂直 sheen（上暗下亮，模拟光从上方进入玻璃）
- 菲涅尔边：`原 alpha − 内缩 alpha` 得到 1px 级轮廓光，上半部更强

**深色 / 着色**
- 深色：底色 `#560A10 → #080102`，材质不变，白字略暗（夜里不刺眼）
- 着色：中性深灰底 + 纯白字标，由系统按用户色调映射

## 6. 复现 / 微调

```bash
# 1) 光栅化标志（macOS 原生，无第三方依赖）
python3 - <<'EOF'
src = open("build/icon/archive-of-our-own.svg", encoding="utf-8").read()
open("/tmp/ao3_white.svg", "w", encoding="utf-8").write(src.replace("#990000", "#FFFFFF"))
EOF
xcrun swift build/tools/render_svg.swift /tmp/ao3_white.svg /tmp/ao3_white.png 2048

# 2) 合成三套外观（可调比例/位置）
P4_MARK=0.72 P4_MARK_Y=0.50 python3 build/tools/make_icon_ao3.py /tmp/icon_out
```

可调参数：`P4_MARK`（字标占比）、`P4_MARK_Y`（纵向中心）。
若想回到「红字白底」的原始感觉，把 `background()` 改成浅底并渲染原色 SVG 即可，但小尺寸可读性会下降。
