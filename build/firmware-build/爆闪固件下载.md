# App 内一键爆闪固件

日期：2026-11-25

这些固件在官方 3.35.2 / 3.35.3 基础上移植了前后爆闪，并额外提供 **HTTP 触发接口**，
所以 App 的「前大灯爆闪 / 后雾灯爆闪」页可以直接一键触发，不需要拨杆手势或滚轮组合。

> 官方 3.35.8 只提供「授权开关 + 拨杆手势」，没有一键触发接口。
> 如果你要 App 内一键爆闪，请用本页的 3.35.3 固件；如果你要 3.35.8 的新功能，二者目前不能兼得。

## 文件选择

| 文件 | 基线 | 芯片 | 功能 | 大小 |
|---|---|---|---|---|
| `P4CAN-v3.35.3-eapnr1-zh-OTA-REV3.X.bin` | 3.35.3 | P4 **v3.x** | 中文 + 前后爆闪 + TLSSC 免重启补发 | 1,571,168 B |
| `P4CAN-v3.35.3-eapnr1-zh-OTA-REV1.X.bin` | 3.35.3 | P4 **v1.x** | 同上 | 1,569,424 B |
| `P4CAN-v3.35.3-strobe1-zh-OTA-REV3.X.bin` | 3.35.3 | P4 **v3.x** | 中文 + 前后爆闪 | 1,568,496 B |
| `P4CAN-v3.35.3-strobe1-zh-OTA-REV1.X.bin` | 3.35.3 | P4 **v1.x** | 同上 | 1,566,736 B |
| `P4CAN-v3.35.2-strobe1-zh-OTA-REV3.X.bin` | 3.35.2 | P4 **v3.x** | 中文 + 前后爆闪（旧基线） | 1,563,104 B |
| `P4CAN-v3.35.2-strobe1-zh-OTA-REV1.X.bin` | 3.35.2 | P4 **v1.x** | 同上 | 1,561,360 B |

- **REV3 / REV1** 是 ESP32-P4 芯片版本，不是固件版本；刷错会起不来。
  不确定时先用 REV3，失败再换 REV1（不会损坏，重新刷即可）。
- **eapnr** 版多了「TLSSC 恢复后免重启」：上电缓存 0x331 并补发 60 秒。
- 3.35.3 版比 3.35.2 多：Lighting Features（AP 强制远光 / 动态刹车灯）、R79 AP 退出修复。

## App 触发接口

| 功能 | 接口 |
|---|---|
| 前大灯爆闪配置 / 状态 / 触发 / 停止 | `GET/POST /api/headlight-strobe/config`、`GET /api/headlight-strobe/stats`、`POST /api/headlight-strobe/trigger`、`POST /api/headlight-strobe/stop` |
| 后雾灯爆闪状态 / 开始 / 停止 | `GET /api/rear-fog-strobe/stats`、`POST /api/rear-fog-strobe/start`、`POST /api/rear-fog-strobe/stop` |

App 3.50 及以上：功能 → 前大灯爆闪 / 后雾灯爆闪，直接设置次数、间隔并触发。

## 刷写

1. App → 设置 → 固件升级 → 选择固件文件，选上表中的 `.bin`（不是 `.merged.bin`）。
2. 上传完成后设备自动重启；首次启动后确认 `fwVersion`：
   - `v3.35.3-strobe1-eapnr1-zh`
   - `v3.35.3-strobe1-zh`
   - `v3.35.2-strobe1-zh`
3. 如果板子是 X179 线束，先到 App「设置 → CAN GPIO」确认/改成：
   - BODY 4/5、CHASSIS 2/3、PARTY 26/27（或反接版 2/3、4/5）
4. 打开「前大灯爆闪」页，设置次数/间隔，点触发；后雾灯页点开始。

## 校验

```bash
shasum -a 256 P4CAN-v3.35.3-eapnr1-zh-OTA-REV3.X.bin
```

完整清单见 `爆闪固件-SHA256.txt`。

## 注意

- 爆闪会实际控制车辆灯光，只在驻车 / 封闭场地测试。
- 3.35.2 / 3.35.3 不是最新官方版本；GPIO、预热、SmartShift、R79 时序等以对应版本为准。
- `eapnr` 版的免重启补发只在「TLSSC 恢复」开启时工作；详见 `3.35.3-EAP免重启移植.md`。
