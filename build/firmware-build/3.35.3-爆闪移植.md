## 2. 相对 3.35.2 的官方变化

- 新增 **Lighting Features**：AP 强制远光、动态刹车灯（Off / Light press / Hard press）
- 修复 AP 退出后 R79 注入
- 新增 `lighting/` 子系统：`lighting_runtime.h`、`lighting_web.h`、三条 `lightingObserve` 钩子、独立 lighting task
- 新接口：`GET /api/lighting/stats`、`POST /api/lighting/update?apForcedHighBeam=&dynamicBrakeMode=`

## 3. 爆闪移植

在 3.35.3 上重复 3.35.2 的移植：

- `headlight_strobe.h` / `rear_fog_strobe.h`
- `vehicle_logic.h`：`headlightStrobeActiveFlag` + 两个 stalk 发送守卫
- `can_runtime.h`：CAN A/CAN B 的 0x273 观察、`headlightStrobeTick` / `rearFogStrobeTick`
- `web_api.h`：8 条爆闪路由 + `hstrobe` NVS
- 与 Lighting 子系统互斥：爆闪期间 `lightingObserve` 直接返回、`lightingService` 清空 AP 远光状态并返回，避免两套 0x249 注入冲突

## 4. 中文界面

中文版使用官方 `zh-CN/dashboard_source.zh-CN.html`，替换 `dashboard_source.html` 后用
`tools/build_dashboard.py` 重新生成 `index_html.h`。中文网页和英文版一样没有爆闪面板，
爆闪控制走 App。

## 5. GPIO

默认仍为 BODY 20/21、CHASSIS 22/23、PARTY 26/27；X179 在 App「设置 → CAN GPIO」改成
4/5、2/3、26/27（或反接版 2/3、4/5），保存后设备重启。NVS `p4gpio` 跨 OTA 保留。
