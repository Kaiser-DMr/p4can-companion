## 2. 移植内容

- `headlight_strobe.h` / `rear_fog_strobe.h`：原样从 v3.29.3 补丁带入。
- `vehicle_logic.h`：`headlightStrobeActiveFlag` + 两个 `sendStalkFrame*` 入口守卫。
- `can_runtime.h`：
  - CAN A party 路径：`0x273` → `rearFogStrobeObserve(0, …)`
  - CAN B 分发：`case 0x273` → `rearFogStrobeObserve(1, …)`
  - `blinkATxTick()` 后调用 `headlightStrobeTick()` / `rearFogStrobeTick()`
- `web_api.h`：`hstrobe` NVS 命名空间 + 8 条路由：
  - `/api/headlight-strobe/{config,trigger,stop,stats}`
  - `/api/rear-fog-strobe/{stats,start,stop}`
- 配置语义与 v3.29.3 补丁一致：次数 1–30、间隔 50–1000 ms、时长/手动停止、安全上限、按住拨杆触发、CAN epoch 中止、恢复确认。

未改 Web Dashboard（v3.35.2 的网页没有加爆闪面板），控制和状态通过 App 使用；接口本身完整。

## 3. 编译

```bash
cd P4-CAN-Universal-v3.35.2
for v in prev3 postv3; do
  arduino-cli compile \
    --fqbn "esp32:esp32:esp32p4:ChipVariant=$v,FlashSize=32M,PartitionScheme=app3M_fat9M_16MB,PSRAM=enabled,USBMode=hwcdc,CDCOnBoot=cdc,FlashMode=qio" \
    --output-dir ../out-3352-$v .
done
```

- `prev3` → REV1.X
- `postv3` → REV3.X

## 4. GPIO

v3.35.2 支持**运行时 GPIO 设置**，编译不再需要 `-DP4CAN_BOARD_X179`。

- 默认引脚：BODY 20/21、CHASSIS 22/23、PARTY 26/27
- X179 线束首次开机：用 App「功能 → 高级与兼容 → CAN GPIO 设置」改成
  **BODY 4/5、CHASSIS 2/3、PARTY 26/27**，保存后设备会停 CAN 并重启
- 也可以直接 `POST /api/system/can-gpio?tx1=4&rx1=5&tx2=2&rx2=3&tx3=26&rx3=27`

保存后确认 `GET /api/system/can-gpio` 的 `active` 已变成新引脚，且三路总线都有帧。
