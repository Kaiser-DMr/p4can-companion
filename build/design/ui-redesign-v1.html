P4 管家 · 界面重设计

把「参数面板」做成「仪表盘」

现在的问题不是某一页不好看，而是没有统一的视觉语言：emoji 图标、三种按钮尺寸、数值与单位各排各的、状态信息在三个地方重复。这份方案给出一套可落地的设计系统，并用真实页面稿验证它在手机与 Mac 上都成立。

版本 v1.0 日期 2026-11-18 适用 iPhone / Mac Catalyst 落地 SwiftUI（iOS 17+）

01 · 现状诊断

A

视觉语言不统一

功能页用彩色 emoji 瓦片，设置页是纯文字行，详情页混用胶囊、卡片、系统行；同一类「入口」有三种长相。

B

按钮没有层级

50pt 全宽填充、44pt 胶囊、行内文字按钮同时出现，主次不分，主操作用户反而要多找一秒。

C

数值可读性差

数值靠右小字、单位混在字符串里、比例字体导致数字跳动；滑动条与步进器混用。

D

状态重复且分散

「爆闪中」在行尾胶囊、状态行、footer 各说一遍；用户需要读三处才能确认当前状态。

E

缺少桌面思路

Mac 版只是把手机列表拉宽，宽屏出现大片空白，信息密度反而低于手机。

F

色彩语义过载

绿/橙/红/蓝随处使用，强调色不唯一，导致「哪一个是主操作」需要靠猜。

02 · 设计目标与原则

像仪表，不像设置

大数字、等宽字形、克制的装饰；一屏之内回答「车在什么状态、我能做什么」。

一个强调色

只有琥珀色代表「可执行的主操作」；绿/红只表示结果状态，不再参与装饰。

熟悉感优先

沿用 iOS 原生导航、分组列表、SF Symbols、系统手势；不发明新交互，只重排层级。

两档信息密度

手机=一次一件事；Mac=同屏两列，指针与键盘可达，不做简单放大。

03 · 整体风格 · Instrument Dark

主推深色「驾驶舱」：车内夜间使用不刺眼，数据对比度高。浅色作为系统跟随的备选，使用同一套层级与强调色，不做第二套设计。

#14181F卡片
#1B2029浮层/次级
#FFB020强调（主操作）
#3DDC97正常
#FF6B6B危险/失败
浅色模式映射：画布 #F6F7F9、卡片 #FFFFFF、强调 #B26A00（保证白底对比度 ≥ 4.5:1）、正常 #0E7A5F、危险 #B3261E。切主题只换 token，不换布局。

06 · 页面布局（手机）

三段式：概览（我现在怎么样）→ 控制（我能做什么）→ 细节（参数与诊断）。所有页面共享同一节奏：16pt 边距、18pt 卡片圆角、12pt 卡片间距。

08 · 关键交互流程

触发爆闪

点按→确认弹窗→胶囊变「爆闪中」→完成/停止

按钮在运行中变为「停止并恢复」，进度用同一行的数值展示，不再另开状态区。

调参数

拖刻度→数值跳动 + 触感→出现「保存」→保存后按钮可用

间隔即时生效（沿用现有逻辑），次数需保存；未保存时主按钮禁用并给出原因。

连接异常

轮询失败→顶部胶囊变「离线」→显示缓存与时间→一键排查

不用弹窗打断；离线横幅只出现一次，内含「排查」入口。

09 · 可访问性与适配

可读性

  • 正文对比度 ≥ 4.5:1，次要文字 ≥ 3:1；深色下不用纯白正文（#F2F5F9）
  • 数值与单位分离，单位不参与字号缩放竞争
  • 动态字体到「辅助功能 XXXL」时，刻度尺间距放大（14 → 26pt），数值行不换行
  • 支持 Reduce Motion：刻度吸附改为淡入，不做长距离弹跳

可操作性

  • 所有可点区域 ≥ 44×44pt；列表行整行可点，不做「只有文字能点」
  • 刻度尺作为 adjustable 元素，VoiceOver 上下滑增减并朗读「当前值 + 单位」
  • 主按钮带 accessibilityHint 说明后果（会控制真实远光灯）
  • Mac 端支持 Tab 聚焦、空格触发、Esc 关闭弹窗

10 · 落地路径

阶段内容风险
P0 · 令牌新增 DesignTokens.swift：色板（深/浅两套）、字号、间距、圆角；现有 Theme 逐步映射到它低，纯新增
P1 · 组件PrimaryButton / SecondaryButton / StatusPill / MetricTile / ControlRow / SectionHeader / RulerSlider（已有雏形）低，可逐页替换
P2 · 页面按 状态 → 功能 → 前大灯/后雾灯 → 设置 的顺序替换；每页保留原有接口与状态字段中，需回归 UI 测试
P3 · 桌面NavigationSplitView + 两列栅格；宽屏 ≥ 900pt 生效中，需在 Mac 实机校对

迁移期间新旧组件可共存，按页面切换，不做一次性大改；每个阶段结束跑一遍「状态页 / 功能页 / 爆闪详情 / OTA / 设置」的回归清单。
