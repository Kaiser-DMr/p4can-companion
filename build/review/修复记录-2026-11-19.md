## 二、P1（已修复）

**状态与数据**
- `BUS-OFF` 不再算在线：`isOnline = state == 1 && trafficOnline`；`P4BusState` 兼容 `BUS-OFF` 连字符。
  验证：把 mock 的 CAN3 置为 BUS-OFF（state=2, ready=true, trafficOnline=false），首页计数显示 **CAN 2/3**（原为 3/3）。
- 「已同步」与缓存标记只在快照成功时更新/清除；慢端点成功不再刷新时间。
- 实时活动：离线持续 60 s 后结束；`staleDate` 8 h → 5 min；创建结果回读，失败回滚开关并提示去系统设置开启。
- 轮询：新增 `isRefreshing` 串行化；批量扫描 `loadAllEndpoints` 期间暂停全局轮询；诊断页 / 无线页遵守 `isPollingPaused`；离线重试不再每次闪「连接中」。
- 扭矩趋势：按 180 s 时间窗（最多 1 s 一点），与「近 3 分钟」一致。
- 快捷开关的总开关提示：只在其命令真正成功时覆盖 toast。

**功能与灯光**
- `command()` 忙时不再静默返回：返回 `Bool` 并提示「设备忙」；LAB/S3XY 总开关只在成功时提示。
- 前大灯间隔滑杆上限 500 → 1000 ms，与固件一致（保存不再静默夹取）。
- vision / window 的能力位改读各自 stats 的 `supported`（`features/status` 没有通用 `supported` 键）。
- 车窗文案改为「Model YL（三电机）· 需车辆静止」。

**设置与维护**
- OTA 失败原因改读 `error`（字符串）；状态页 OTA 失败提示同步修正（原来按布尔读，永不显示）。
- OTA 进度在离开再进入时复位，不再永远停在 100%。
- 无线：只改密码时自动回填当前 SSID；失败保留输入。
- TLSSC 恢复：需先开启「封禁车辆」；能力位缺失不再默认支持；文案改为「仅封禁后使用」；离线禁用。
- 封禁车辆：`featuresStatus` 未加载时按不支持处理，离线禁用。
- 选包：校验 ESP32 镜像魔数 `0xE9`。
- 设备地址：键盘改 `.URL`（可输端口/scheme）；成功后回写输入框并提示。
- 车型保存：离线禁用、当前车型禁用；回读窗口 20 → 45 s；超时文案改为「已提交，待确认」。
- 删除重复且会把失败当成功的 `AppEnvironment.applyWiFi`。
- 蓝牙标签：与 BLE 总开关解耦，显示过即保持，关掉开关后仍能回到该页重开。
- 连接引导：删除与固件不符的「家庭 Wi-Fi 改新 IP」段；标题/按钮本地化。

## 七、第六轮：前大灯保存修复（3.36 / build 57）

用户反馈「修改了数据无法保存」。逐条消除所有会导致“按钮能点但保存不生效”的路径：

| 可能原因 | 处理 |
|---|---|
| 爆闪进行中固件对 config POST 回 409，而保存按钮因 `active` 直接变灰 | 保存按钮不再因 active 禁用；点保存时先 `stop()` 并等状态落地，再写参数；按钮下方说明「保存会先停止并恢复」 |
| 参数越界时 `guard` 静默 return，界面毫无反馈 | 越界改为 toast，列出次数/间隔/时长/上限的具体值 |
| 请求失败只在页面底部显示错误行，容易看不到 | 失败同时弹 toast（中文原因来自 `friendly()`） |
| 固件忽略不认识的参数、或 NVS 写失败仍回 200，App 却标记已保存 | 保存后用响应回读比对 count / mode / maxRunMs；不一致则回滚 `saved`、保留未保存状态并提示回读值 |
| `busy` 在任务取消时可能停在 true，之后按钮永久禁用 | `defer { busy = false }` 兜底 |

仍未定位用户设备的实际原因（未拿到报错文案）；本轮保证无论哪条路径都会给出可见原因，而不是静默失败。

## 八、第七轮：保存/撤销按钮点不动（3.37 / build 58）

用户反馈改完参数后「保存参数」「撤销未保存修改」都没有反应。用 DEBUG 读数确认状态是对的
（`dirty=true saveDisabled=false revertDisabled=false count=13/12`），问题在点击没到按钮：

| 原因 | 处理 |
|---|---|
| `ElasticButton` 自带 `DragGesture(minimumDistance: 0)`，在 List 里与滚动手势抢识别，按下有动画但 Button 不触发 | `ElasticButton` 增加 `tracksDrag` 开关；这两颗按钮改为 `tracksDrag: false`（保留按压回弹/液面，不跟手拖拽） |
| 按钮所在行贴近自定义浮动标签栏，底部可能被栏的命中区域盖住 | List 增加 `.contentMargins(.bottom, 28)`，最后两行抬到标签栏上方 |

上一轮加的「保存前停止 / 越界提示 / 失败 toast / 回读校验」保留；本轮解决的是“根本点不到”。

### 构建环境注意

本机 `swift-plugin-server` 启动时报 `sandbox-exec: sandbox_apply: Operation not permitted`，
导致 SwiftUI 宏展开失败（`StateMacro could not be found`）。构建需追加：

```
OTHER_SWIFT_FLAGS='$(inherited) -disable-sandbox'
```

这是本机环境问题，与工程配置无关；换机或修复 sandbox 后可去掉。
